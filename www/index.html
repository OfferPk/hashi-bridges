How to play

Connect the numbered islands with bridges:

  • Bridges run only horizontally or vertically.
  • At most two bridges between the same pair.
  • Bridges never cross and never pass through islands.
  • Each island’s number equals how many bridge ends touch it.
  • All islands must form one connected network.

Tap an island to select it, then tap another in line to cycle 0→1→2 bridges.
