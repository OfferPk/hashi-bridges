THE BASICS

How to play

Connect the numbered islands with bridges:

  • Bridges run only horizontally or vertically.
  • At most two bridges can connect the same pair.
  • Bridges never cross or pass through another island.
  • Each island’s number equals the bridge ends touching it.
  • Every island must belong to one connected network.

Tap an island, then tap another in a clear line to cycle 0 → 1 → 2 bridges. On a keyboard, use the arrow keys and Enter.
